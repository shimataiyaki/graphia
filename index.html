アプリケーション概要 (About Graphia)

Graphia（グラフィア）は、ブラウザ上で滑らかに動作するオリジナル設計のインタラクティブ関数グラフ計算機・数学ビジュアライザーです。陽関数・陰関数・極座標・媒介変数曲線・座標点プロット・動的パラメータスライダーのリアルタイム描画に対応しています。

使用ライブラリ・依存関係 (Libraries & Dependencies)

  • 外部JavaScriptライブラリ：なし（Zero External Dependencies）
    サードパーティ製の数式評価ライブラリ、グラフ描画ライブラリ、UIフレームワークは一切使用せず、100% Pure HTML5 / CSS3 / Vanilla JavaScript (ES2023+) のみで独自実装されています。
  • アイコン・グラフィック素材：
    アプリアイコンおよびすべてのUIボタンアイコンは、本アプリケーション用に独自設計したインラインSVGベクターグラフィックを使用しています（外部アイコンフォント・外部画像ファイル未使用）。
  • フォント：
    各OS標準のシステムフォントスタック（Segoe UI Variable / Segoe UI / San Francisco / Yu Gothic UI / Hiragino Kaku Gothic ProN / Cascadia Code / Consolas）を参照しており、外部フォントCDNへの通信やフォントファイルの再配布は行っていません。
  • Web標準ブラウザAPI：
    HTML5 Canvas 2D API（高DPIグラフ描画・PNG書き出し）、ResizeObserver API（ビューポートサイズ追従）、Pointer Events API（マウス・タッチ操作統合）。

採用アルゴリズム・数学的手法 (Mathematical Algorithms)

  • Recursive Descent Parser（再帰下降構文解析）：
    独自の字句解析器と再帰下降パーサにより、暗黙の乗算（例：2x, 3sin(x), (x+1)(x-1)）や数学関数・定数を安全に構文解析して評価します。
  • Marching Squares Algorithm（マーチングスクエア法）：
    陰関数方程式 f(x, y) = g(x, y) の等高線（ゼロ等値線）を線形補間付きグリッド走査によって高速かつ滑らかに抽出します。
  • Brent's Method & Bisection Method（ブレント法・二分法ハイブリッド）：
    関数のx切片および複数曲線間の交点を、符号変化区間から高精度に数値収束させて自動検出します。
  • Golden-section Search（黄金分割探索法）：
    導関数を必要としない単峰性区間探索により、曲線の極大値・極小値を安定して特定します。

プライバシーと設計指針 (Privacy & Design Principles)

  • 完全ローカル動作・ゼロ通信：
    すべての数式解析・数値計算・描画処理はご利用のブラウザ内のローカルメモリ上で完結します。外部サーバーへのデータ送信、アクセス解析、Cookieトラッキングは一切行いません。
  • UIデザイン設計：
    モダンなデスクトップアプリの視覚原則（アクリル半透明質感、明確なタイポグラフィ階層、ライト／ダーク両テーマでのアクセシブルなコントラスト比）を参考に独自CSSで設計しています。
